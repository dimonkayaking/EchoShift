# EchoShift

## Запуск

Запускай из папки `EchoShift`:

```bash
cd EchoShift
dotnet run
```

## Управление

- **WASD / стрелки**: движение
- **ЛКМ**: стрельба
- **Space**: телепорт на позицию “эха” (стоит **20 Echo**)
- **Tab**: открыть режим **Roulette** (ставки Echo)
- **Esc**: пауза / продолжить
